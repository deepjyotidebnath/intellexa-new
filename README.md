# Intellexa website (Next.js 14 + Tailwind)
Setup: `npm install` · Dev: `npm run dev` · Build: `npm run build && npm start`
Deploy (Vercel): push to GitHub, import repo, add env var FORM_ENDPOINT (see .env.example), add domain intellexa.online.

## Fill in before launch
Search for `[` in the code. Key ones: founder name/bio, city, address, GSTIN, email, Website+Hosting price, Meta charges wording, trial contents, refund rules, real case study/testimonials, Search Console code, GA4 ID, /public/og.png (1200x630), favicon files.

## Assumed
Email hello@intellexa.online; Hindi+English only; Meta charges undecided; plans monthly in INR.

## Not yet included
Dark-mode toggle, cookie banner + GA4 events, JSON-LD Product/Offer, favicon/manifest, Framer Motion, detailed services copy.

## Post-launch
GA4 + Search Console verified, submit sitemap, Google Business Profile, SSL check, PageSpeed test, test form and WhatsApp links on a phone, lawyer review of legal pages.
